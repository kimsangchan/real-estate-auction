# Scope Options — MVP / Standard / Enterprise

작성일 2026-07-07. 각 기능의 근거는 01-domain-discovery의 유사 솔루션 조사 결과를 인용.

## 한눈에 비교

| | S1. MVP (경매 특화) | S2. Standard (통합 플랫폼) | S3. Enterprise (엔드투엔드) |
|---|---|---|---|
| 한 줄 정의 | "경매를 네이버부동산만큼 쉽게" — 경매 탐색 + 자동 권리분석 | MVP + 일반 매물 광고 + 커뮤니티 | Standard + 금융·입찰대행 연계 + B2B |
| 개발 기간 감 (1~2인) | 3~5개월 | +4~6개월 | +6개월~ |
| 필요 외부 계약 | 등기부 중계 API 1건 | + 중개사 제휴 영업, KISO 가입 | + 금소법 등록, 대리인 제휴, 제휴 은행 |
| 규제 리스크 | 변호사법 경계 설계(필수) | + 표시광고 의무, 모니터링 협조 | + 금소법, 매수신청대리 규칙 |

## S1. MVP — 경매 특화 (추천)

| 기능 | 내용 | 근거 (조사 출처) |
|---|---|---|
| 지도 기반 경매 물건 탐색 | 지도 bbox + 필터(유형·가격대·기일·유찰횟수), 클러스터링, 지적편집도 | 3사 공통 강점 = 지도 UX가 업계 표준 (01 §4-4). 네이버 SDK 지적편집도 내장 |
| 물건 상세 | 감정가·최저가·기일 이력, 법원 서류 3종 원문 링크, 실거래가·주변 시세 컨텍스트 | 법원 문서 재배포 적법 (저작권법 §7), 실거래가 무료 API (01 §5) |
| 자동 권리분석 1단계 | 말소기준권리 판별, 인수/말소 분류, 임차인 대항력 비교, 소액임차인 판정, 예상배당표(추정치 면책) | 탱크옥션·두인 등 업계 표준 기능을 룰 엔진으로 재현 (01 §1-3) |
| 위험 경고 2단계 | 매각물건명세서 위험 키워드 감지 → 경고 배지("전문가 확인 필요") | 지지옥션도 특수권리는 전문가 처리 — 판단하지 않고 표시만 (A-02) |
| 임장 체크리스트 | 전입세대확인서 등 온라인 불가 항목의 현장 확인 목록 자동 생성 | 전입세대 열람 온라인 불가 확인 (01 §5) |
| 용어 쉬운 설명 | 모든 전문용어 툴팁·풀어쓰기 (UX-03: 병기율 100%) | 기존 경매 서비스의 용어 장벽이 차별화 축 (01 §4-4) |
| 관심 물건 알림 | 기일 변경·유찰 시 푸시 | 탱크옥션 문자알림 벤치마크 |
| 계정/로그인 | 카카오·네이버·애플 소셜 로그인 (Apple 지침 4.8) | 04 카드 C-08 |

**제외**: 일반 매물 광고(A-04), 입찰 대행, 생성형 AI 요약(변호사법·AI기본법 검토 후), 사용자 GPS(LBS 신고 회피 — 지도에 물건 위치만 표시).

## S2. Standard — 통합 플랫폼

MVP 성과(사용자 확보) 후 진행. 추가 기능:

| 기능 | 근거 |
|---|---|
| 중개사 제휴 일반 매물 광고 (표시·광고 명시사항 검증 UI 내장) | 다방 직접 등록 모델 벤치마크. KISO 가입 (01 §3-2) |
| 매물 ↔ 경매 교차 뷰 ("이 단지 경매 물건 N건") | 리치고 대비 차별화 — 3사·리치고 모두 미제공 (01 §4-3) |
| 단지·동네 커뮤니티 (후기) | 호갱노노 커뮤니티 성공 사례 (01 §4-3) |
| 낙찰가율 통계·낙찰가 예측 | 지지옥션 통계 공신력 벤치마크 |
| 전문가(매수신청대리인) 연결 | 미스고 대리입찰 매칭 모델. 알선 수수료 구조는 변호사 검토 선행 |
| 유료 프리미엄 검토 (A-03 재평가) | 옥션원 연 92.6만원 시장 — 가격 파괴 포지션 |

## S3. Enterprise — 엔드투엔드

| 기능 | 근거·전제 |
|---|---|
| 경락잔금대출 비교 | 금소법 대출성 상품 판매대리·중개업 등록 필수 (01 §3-2). 네이버페이 금융 연계 벤치마크 |
| 생성형 AI 물건 요약·Q&A | AI 기본법 고지 의무 + 변호사법 경계 재검토 (개별 판단 출력 금지) |
| 전자계약·낙찰 후 절차 관리 (명도 일정 등) | 다방싸인 벤치마크. 경매는 여정이 길어 엔드투엔드 커버 기회 (01 §4-4) |
| B2B 데이터 API | 지지옥션 B2B 모델 벤치마크 |
| ISMS-P 인증 | 이용자 100만/매출 100억 트리거 도달 시 (01 §3-2) |
