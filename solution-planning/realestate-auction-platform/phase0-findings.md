## 0-2. 등기부 데이터 소스 확인 — ✅ 방향 확정

사용자 제공 URL(등기정보광장 오픈API, https://data.iros.go.kr/rp/oa/openOapiAppl.do) 분석 결과:

| 항목 | 확인 내용 |
|---|---|
| 제공 데이터 | **등기현황 "통계" 데이터** — 부동산/법인 등기 신청현황(2010~), 확정일자(임대차 통계), 등기사항증명서 열람/발급 통계(2018.8~) 등 (https://data.iros.go.kr/rp/ir/openRgsDataIntro.do) |
| **개별 부동산 등기부 원문** | **제공하지 않음** — 오픈API로 특정 부동산의 등기사항전부증명서를 받을 수 없음 |
| 이용 조건 | 회원 누구나 **무료**, 서비스별 인증키, **승인 절차 없이 즉시 사용**, **일 최대 1,000건**, 3개월 미사용 시 키 자동 삭제 (openOapiIntro.do, 확인일 2026-07-07) |

**결론**:
1. 권리분석용 개별 등기부는 **기존 계획 유지** (D-008): 인터넷등기소 열람 실비 700원/건 + CODEF/하이픈 중계 API. CODEF 무료 데모(3개월, 일 100회) 신청은 사용자 액션 필요 (codef.io 회원가입 + 사업자 정보).
2. 등기정보광장 오픈API는 **보조 데이터 소스로 채택** (신규): 확정일자 통계(지역별 임대차 동향), 소유권이전등기 현황 등 — 무료 시장 컨텍스트 데이터로 물건 상세의 "동네 시세 맥락"에 활용 가능. 일 1,000건 한도는 통계 용도로 충분.

## 0-3. NCP 그린하우스 신청 요건 — ✅ 확인 (신청은 사용자 액션 필요)

- 혜택: 크레딧 **최대 1억원, 최대 2년 분할**, 전 상품 사용 가능, 기술 컨설팅 포함 (https://www.ncloud.com/support/greenHouse, https://greenhouse.oopy.io/)
- **자격**: 그린하우스 **제휴 기관(VC·액셀러레이터·지원사업)으로부터 투자 또는 수혜를 받은 스타트업** — 아무나 신청 불가
- 신청 절차: ① NCP **사업자 계정** 생성(사업자등록증 필요) ② 제휴 기관 리스트 확인 후 해당 기관 경유 신청 ③ 지급은 영업일 ~5일 (https://greenhouse.oopy.io/application)
- **사용자가 직접 해야 할 일**:
  1. 사업자등록 (아직 없다면 — 개인사업자로 가능)
  2. greenhouse.oopy.io 제휴 기관 리스트에서 접근 가능한 지원사업 확인 (창업지원사업·액셀러레이터 등)
  3. 제휴 기관 미해당 시 대안: NCP 신규 가입 크레딧(소액) → 초기 개발은 소액으로 충분 (월 20~40만원 추정, 06 §6), 투자·지원사업 수혜 시점에 그린하우스 재신청. AWS Activate Founders($1,000)도 병행 검토
