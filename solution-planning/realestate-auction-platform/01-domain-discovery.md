## 1. 도메인 개념과 업무 흐름

### 1-1. 일반 매물 시장 구조 (누가 매물을 올리는가)

- 매물 광고는 법적으로 **개업공인중개사만** 올릴 수 있다 (무자격자의 중개 목적 광고는 형사처벌 — 공인중개사법 §18조의2·§49, https://casenote.kr/법령/공인중개사법/제18조의2, 2026-07-07).
- 네이버부동산: 중개사가 직접 등록하는 게 아니라 **CP(제휴 정보업체) 경유** — 매경부동산, 아실, 피터팬 등을 거쳐 노출. 건당 약 9,900원 (https://entpmkt.com/22, 2026-07-07).
- KB부동산: 협력 중개사(KB Houstar)가 중개사허브로 등록 (https://agent.kbland.kr/, 2026-07-07).
- 다방: 중개사 직접 등록(다방프로) + 임대인 직접 등록. 광고 슬롯 판매(10칸 월 198,000원, 2017~19년 보도 기준 — 현행가 미확인) (https://www.etoday.co.kr/news/view/1653779, 2026-07-07).
- **시사점**: 신생 플랫폼이 일반 매물을 확보하려면 중개사 영업(제휴)이 필요 — 기술이 아니라 영업의 문제. 크롤링으로 대체 불가(아래 3-3).

### 1-2. 법원경매 절차 (7단계, 쉬운 설명)

출처: 찾기쉬운 생활법령정보 (https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=306&ccfNo=1&cciNo=1&cnpClsNo=3), 대법원 법원경매정보 (courtauction.go.kr), 확인일 2026-07-07.

| 단계 | 쉬운 설명 |
|---|---|
| ① 경매개시결정 | 돈 못 받은 채권자가 법원에 신청 → 등기부에 "경매 진행 중" 기록 |
| ② 배당요구종기 | 이 부동산에서 돈 받을 사람(세입자 등)이 신고해야 하는 마감일 |
| ③ 매각 준비·공고 | 법원이 감정평가(가격 산정) + 현황조사(누가 사는지) 후 입찰일 공고 |
| ④ 매각기일(입찰) | 법원에서 봉투 입찰. 최고가 쓴 사람이 낙찰 후보 |
| ⑤ 매각허가결정 | 1주 뒤 법원 심사로 낙찰 확정 (+1주 이의제기 기간) |
| ⑥ 대금납부 | 잔금 납부 순간 소유권 취득 |
| ⑦ 배당 | 법원이 낙찰대금을 순위대로 채권자에게 분배 |

입찰자의 실제 여정: **물건 검색 → 권리분석 → 임장(현장조사) → 입찰 → 명도(점유자 내보내기)**. 명도는 잔금납부 후 6개월 내 인도명령 신청 가능 (https://www.yklawfirm.co.kr/blog/estate/12666, 2026-07-07).

핵심 법원 서류 3종 (모두 courtauction.go.kr에서 무료 열람):
- **매각물건명세서**: 낙찰자가 떠안는 권리를 법원이 요약한 공식 문서. 권리분석의 최종 근거.
- **현황조사서**: 집행관이 현장에서 점유·임대차 관계를 조사한 보고서.
- **감정평가서**: 감정평가사가 산정한 가격 보고서 (민간 작성 — 재배포 시 저작권 주의, §3-2).

### 1-3. 권리분석 (이 기획의 핵심 도메인)

권리분석 = 낙찰가 외에 **추가로 떠안는 권리·보증금이 있는지** 등기부와 법원 서류로 확인하는 작업 (https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=306&ccfNo=2&cciNo=1&cnpClsNo=2, 2026-07-07).

- **말소기준권리**: 등기부의 6종 권리(저당·근저당·압류·가압류·담보가등기·경매개시결정등기) 중 가장 먼저 등기된 것. 이보다 **뒤의** 권리는 낙찰로 지워지고, **앞의** 권리는 낙찰자가 인수. → "날짜 정렬 + 규칙 비교"라 **소프트웨어 구현 가능**.
- **임차인 분석**: 세입자의 대항력 발생 시점(전입신고 다음 날 0시)이 말소기준보다 빠르면 보증금 인수 위험. 확정일자·배당요구 여부에 따라 결과가 갈림.
- **소액임차인 최우선변제**: 2026-07-07 현재 유효 기준은 2023-02-21 시행 시행령(서울 보증금 1.65억 이하 → 최대 5,500만원 우선배당). **기준 시점이 "최초 담보 설정일"이라 과거 개정 이력 테이블 전체가 필요** (https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=130113, 2026-07-07).
- **자동화 불가 영역**: 유치권·법정지상권·분묘기지권은 등기부에 없어 서류만으로 판별 불가. 업계 1위 지지옥션도 특수권리 13종은 **사람(전문가)이 분석** (https://www.sedaily.com/NewsView/1KSD8GIZA3, 2026-07-07).

**권리분석 자동화 3단계 경계** (조사 결과 종합):
1. **완전 자동(룰 엔진)**: 등기부 파싱 → 말소기준 판별 → 인수/말소 분류, 대항력 비교, 소액임차인 판정, 예상배당표
2. **반자동+경고**: 매각물건명세서 텍스트에서 위험 키워드(유치권 신고, 지분매각, 대지권 미등기 등) 탐지 → 경고 배지 + 임장 체크리스트 자동 생성
3. **전문가 영역**: 유치권·법정지상권 성립 판단 등 — 소프트웨어가 판단하지 않고 "전문가 연결"로 처리 (면책·변호사법 양면에서 안전)

## 3. 공식 표준·규제 (요약 — 상세는 02-assumption-pack, 06-tech-blueprint에 매핑)

### 3-1. 사업모델을 좌우하는 3대 고위험 규제

1. **변호사법 §109 (자동 권리분석)** — 비변호사가 대가를 받고 법률 판단을 제공하면 7년 이하 징역. 2025-02 로폼 사건 대법원 확정: "정형 규칙 기반 정보 정리는 법률사무 아님, 개별 사건 판단·자문은 위반 소지" (https://www.lawtimes.co.kr/news/articleView.html?idxno=218044, 2026-07-07). → **출력을 "규칙 기반 정보 정리 + 참고자료"로 한정, "입찰해도 됨/안 됨" 식 판단 문구 금지.** 면책 문구는 민사만 줄일 뿐 형사 리스크를 없애지 못함.
2. **개인정보 (PIPC 의결 2019-05-057)** — 경매·등기 공개정보의 영리 활용은 허용되나, **경매 종료 후 개인정보 계속 게시는 금지**(목적 달성 → 파기). 전입세대 정보 게재 금지 (https://casenote.kr/개인정보보호위원회/제2019-05-057호, 2026-07-07). → 사건 종료 감지 → 소유자명 자동 마스킹 파이프라인을 MVP 데이터 모델에 내장.
3. **크롤링/무등록 중개** — 네이버부동산 매물 DB 크롤링은 DB제작자권 침해로 패소 사례 확정(다윈중개 2심 패소 2026-01, https://www.etnews.com/20260102000213, 2026-07-07). 민간 플랫폼 매물은 제휴로만 확보. 플랫폼이 거래를 직접 알선하면 무등록 중개(3년 이하 징역). courtauction.go.kr 약관·robots 원문은 **미확인 — 개발 착수 전 확인 필수**.

### 3-2. 그 외 준수 사항

- 중개대상물 온라인 표시·광고 명시사항 + 국토부(한국부동산원) 모니터링 협조 의무 — 매물 광고 게재 시 (https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulId=73758&efYd=0, 2026-07-07)
- KISO 부동산매물클린관리센터 가입 — 매물 광고 시 업계 표준 (https://report.kiso.or.kr/realty/, 2026-07-07)
- 법원 작성 문서(매각물건명세서 등)는 저작권법 §7로 재배포 가능. **감정평가서는 민간 저작물 — 요지 발췌 + 원문 링크 방식이 보수적** (https://casenote.kr/법령/저작권법/제7조, 2026-07-07)
- 위치기반서비스 신고(사용자 GPS 사용 시, 소상공인 특례로 개시 후 1개월 내), 통신판매업 신고(유료화 시), ISMS-P(매출 100억/일평균 이용자 100만 도달 시), AI 기본법(생성형 AI 기능 도입 시 고지 의무, 2026-01-22 시행)
- 매수신청대리(입찰 대행)는 변호사·법무사·등록 중개사만 — 플랫폼은 제휴 연결 모델로 (https://law.go.kr/법령/공인중개사의매수신청대리인등록등에관한규칙/(02104), 2026-07-07)
- 대출 비교 기능은 금소법상 대출성 상품 판매대리·중개업 등록 후에만 (https://better.fsc.go.kr/fsc_new/replyCase/LawreqDetail.do?stNo=11&muNo=85&muGpNo=75&lawreqIdx=3453, 2026-07-07)

### 4-4. 기회 영역 종합 (3사 공통 약점 × 경매 시장 구조)

1. **경매 공백(부분)**: 대형 3사는 경매 미취급/단순 정보 수준. 단 **아실이 무료 지도 기반 경매 정보를, 리치고가 AI 권리분석을 선행** — "경매 정보를 무료로 보여주는 것" 자체는 더 이상 공백이 아님
2. **남은 진짜 공백 = 입문자용 권리분석 UX**: 아실은 서류 원문만 제공(해석은 사용자 몫), 리치고는 생성형 AI 방식(변호사법 경계 리스크), 유료 사이트는 전문가 지향. **"룰 기반으로 안전하게 + 용어를 풀어서 + 인수 금액을 자동 계산해주는 입문자용 권리분석"은 어느 곳도 제공하지 않음**
3. **신뢰 문제 역이용**: 경매 물건은 법원 공고 기반이라 **허위매물이 구조적으로 불가능** — "100% 실물건" 포지셔닝 가능
4. **가격 기준선 상향**: 아실의 무료 선행으로 경매 물건 목록·서류 열람은 무료가 시장 기준선 — 유료화 가능 지점은 권리분석 심화·알림 등 부가가치 층위로 이동 (A-03 무료 시작 가정을 강화하는 근거)
