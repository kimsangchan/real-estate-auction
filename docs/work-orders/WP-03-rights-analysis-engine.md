## 목적
등기 권리 목록 + 임차인 정보를 입력받아 말소기준권리·인수/말소 분류·대항력·소액임차인·예상배당을 산출하는 **순수 함수형 도메인 모듈**을 `apps/api`(NestJS) 안에 만든다. HTTP 레이어는 이번 범위가 아니다.

## 도메인 규칙 (01-discovery §1-3 근거 — 구현 전 반드시 원문 읽기)
1. **말소기준권리**: (근)저당권·(가)압류·담보가등기·경매개시결정등기 중 접수일 최선순위. 예외: 선순위 전세권(건물 전부 + 배당요구 시)
2. **인수/말소**: 말소기준 이후 = 말소(원칙), 이전의 용익물권·가처분·가등기 = 인수. 유치권·법정지상권·분묘기지권 = 등기 외 권리로 **판별 불가 → "확인 필요" 플래그만**
3. **임차인**: 대항력 = 전입일 다음 날 0시 발생 → 말소기준 접수일과 비교. 확정일자·배당요구 여부로 우선변제·인수 잔액 계산
4. **소액임차인**: 기준 시점 = **최초 담보물권 설정일** → 시행령 개정 이력 테이블(2023-02-21 현행 포함 전체 연혁)을 seed 데이터로 포함. 출처: law.go.kr 연혁 (01 §1-3)
5. **예상배당표**: 배당 순위 규칙 단순화 버전(경매비용 → 최우선변제 → 우선변제 순) — 정밀 배당은 v2

## 요구사항 (설계)
1. 구조 (규칙 2·3): `rights-analysis/` 모듈 — `domain/`(순수 함수·엔티티), `dto/`(입출력 + class-validator 검증, 규칙 5), `service/`(오케스트레이션). Controller 없음
2. **모든 판정 결과에 `ruleId` + `ruleVersion` 포함** (06 §2 — 감사·면책 방어). 룰 정의는 코드 상수가 아닌 버전 태그된 테이블/객체로
3. **출력에 판단·권유 문구 금지** (D-011): enum 상태값(`EXTINGUISHED`/`ASSUMED`/`NEEDS_REVIEW`)과 금액만. 사용자 문구는 별도 카피 레이어(이번 범위 아님)
4. 총 부담액 계산기: 입찰가 입력 → 입찰가 + 인수보증금 합계 (UX-02의 백엔드)
5. 단위 테스트 (규칙 11) — 최소 케이스:
   - 정상: 단순 근저당 1건(전부 말소), 선순위 임차인 인수, 배당요구한 대항력 임차인(인수 0)
   - 경계: 전입일 = 말소기준 접수일(다음 날 0시 규칙), 담보 설정일이 시행령 개정일 당일, 배당요구종기 이후 배당요구
   - 실패: 필수 필드 누락 DTO → 초기 차단 (규칙 5)
   - 판별 불가: 유치권 신고 키워드 → NEEDS_REVIEW
